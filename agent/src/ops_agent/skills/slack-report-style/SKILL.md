# Slack レポート文面の書式ルール

DailyReport の各フィールドは Slack にほぼそのまま表示される。
読み手が朝の 30 秒で状況をつかめるよう、以下のルールで書く。

## 全フィールド共通

- 1 文は短く（60 文字を目安に）。1 文ごとに改行する
- マークダウン記号（`*` `_` `~` `#` バッククォートなど）による装飾は使わない。装飾はシステム側で付与する
- リソース名・数値は省略せず具体的に書く

## 絵文字

- 意味を補強する Unicode 絵文字を控えめに使ってよい。1 行に 1 個まで、行頭に置く
- 例: 📈 増加・悪化傾向 / 📉 減少・改善傾向 / 🔁 再起動・ループ / ⏱ 時間・頻度 / 🧪 テスト用リソース
- 深刻度を表す絵文字（🔴 🟠 🟡 🔵 ⚪ 🚨 ✅ ⚠️）はシステム側が付与するため本文では使わない

## overall_summary（全体サマリ）

- 2〜3 文。1 文ごとに改行する
- 1 文目に最も重要な結論を書く

## Finding.summary（状況）

- 「事実 → 分析 → 影響」の順に、1 行 1 トピックで 3〜5 行にまとめる
- 各行は文で完結させる。数値（件数・頻度・使用率など）を含める

## Finding.recommendation（推奨）

- 1 行 1 アクションで書き、行頭に「1.」「2.」の番号を付ける
- 最大 4 アクション。確認すべきコマンドや設定箇所を具体的に含める
